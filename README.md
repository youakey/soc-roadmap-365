# SOC Roadmap 365

Личный трекер годового плана перехода из «Tech Level 2» в **Junior SOC Analyst**.
52 недели · 631 технический час · 224 задачи · старт 03.08.2026 → финиш 01.08.2027.

Работает без сервера и без сборки: чистый HTML + CSS + JavaScript.
Весь прогресс хранится **только в твоём браузере** (`localStorage`) и никуда не отправляется.

## Что внутри

| Вкладка | Что делает |
|---|---|
| **Сегодня** | Чеклист дня (5 блоков по 10/15/45/100/10 мин), таймер на каждый блок, карточка текущей недели, streak, правило дня |
| **Год** | Кольцо прогресса, часы план/факт, разбивка по 4 кварталам, 4 контрольные точки с полями для факта, протокол отставания, красные флаги |
| **Недели** | Все 52 недели с задачами-чекбоксами, deliverable, полями «часы факт / статус / оценка / блокеры». Фильтры по кварталу, статусу, экзаменам |
| **Карьера** | 8 репозиториев портфолио с чек-листом, трекер откликов (цель 60), карта рынка, шаблон CV и холодного письма |
| **Ещё** | Дневной блюпринт, метод чтения документации на A1, языковые треки, ~40 ресурсов со ссылками, разбор железа, справочник команд, Windows Event ID, 50 вопросов интервью, шаблон incident report, бюджет, все правила, бэкап данных |

## Деплой на GitHub Pages

### Вариант A — через терминал VS Code (3 минуты)

1. Создай пустой репозиторий на GitHub: **New repository** → имя `soc-roadmap-365` → **Public** → без README.

2. Открой папку проекта в VS Code (`File → Open Folder`), затем `Terminal → New Terminal` и выполни:

```bash
git init
git add .
git commit -m "SOC Roadmap 365"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/soc-roadmap-365.git
git push -u origin main
```

3. На GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.

4. Через 1–2 минуты сайт живёт по адресу:
   `https://ТВОЙ_ЛОГИН.github.io/soc-roadmap-365/`

### Вариант B — без терминала

Repository → **Add file → Upload files** → перетащи все файлы → **Commit changes** → дальше пункт 3 выше.

## Про PIN и приватность

- PIN из 4 цифр защищает страницу **от случайных глаз**, не более того.
- Это не шифрование: код страницы публичный, и человек, который откроет DevTools, PIN увидит. Ничего секретного туда не клади.
- Твои данные (часы, заметки, отклики) при этом **физически не покидают браузер** — их нет ни в репозитории, ни на сервере. Открыв твою ссылку, посторонний увидит пустой трекер.
- Забыл PIN? Очисти данные сайта в браузере — сбросится вместе с прогрессом. Поэтому делай бэкапы.

## Бэкапы — обязательно

Прогресс живёт в `localStorage`. Он **исчезнет**, если очистить данные сайта, переустановить браузер или зайти в приватном окне.

**Раз в месяц:** вкладка «Ещё» → **Скачать бэкап** → сохрани JSON.

**Синхронизация Mac ↔ iPhone** (вручную, автоматической нет):
Mac → «Скачать бэкап» → отправь файл себе в Telegram → на iPhone «Загрузить бэкап».

## Структура

```
soc-roadmap-365/
├── index.html            разметка и точка входа
├── styles.css            дизайн-система, тёмная + светлая тема, адаптив
├── data-weeks.js         52 недели (сгенерировано из roadmap)
├── data.js               ресурсы, портфолио, справочники, бюджет
├── store.js              localStorage, прогресс, экспорт/импорт
├── app.js                рендеринг и логика
├── manifest.webmanifest  PWA — иконка на экране «Домой»
└── icon.svg              иконка
```

Чтобы поправить содержание недели — правь `data-weeks.js`.
Чтобы добавить ресурс — массив `RESOURCES` в `data.js`.
Чтобы поменять цвета — CSS-переменные в начале `css/styles.css`.
