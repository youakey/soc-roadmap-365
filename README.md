# SOC Roadmap 365

Личный трекер годового плана перехода из «Tech Level 2» в **Junior SOC Analyst**.
52 недели · 631 технический час · 224 задачи · старт 03.08.2026 → финиш 01.08.2027.

Работает без сервера и без сборки: чистый HTML + CSS + JavaScript.
Весь прогресс хранится **только в твоём браузере** (`localStorage`) и никуда не отправляется.

## Про PIN и приватность

- PIN из 4 цифр защищает страницу **от случайных глаз**, не более того.
- Это не шифрование: код страницы публичный, и человек, который откроет DevTools, PIN увидит. Ничего секретного туда не клади.
- Твои данные (часы, заметки, отклики) при этом **физически не покидают браузер** — их нет ни в репозитории, ни на сервере. Открыв твою ссылку, посторонний увидит пустой трекер.
- Забыл PIN? Очисти данные сайта в браузере — сбросится вместе с прогрессом. Поэтому делай бэкапы.

## Синхронизация Mac ↔ iPhone (Supabase)

Прогресс дублируется в собственный Supabase-проект. Работает офлайн-первым:
без сети и без входа приложение работает как раньше, локально.

### Что нужно сделать один раз

1. **Создать проект** на supabase.com → New project (имя `soc-roadmap`, регион ближе к Европе).
   При создании Supabase попросит придумать пароль базы данных — сохрани его в менеджере паролей,
   в самом приложении он не нужен.
2. **Выполнить SQL**: Supabase → SQL Editor → New query → вставить содержимое `supabase.sql` → Run.
   Это создаёт таблицу `progress` и включает Row Level Security.
3. **Забрать ключи**: Supabase → Project Settings → API → скопировать `Project URL` и `anon public`.
4. **Вписать их в `config.js`** вместо заглушек и закоммитить.

### Почему anon-ключ можно держать в публичном репозитории

Так задумано в Supabase: `anon` — это не секрет, а идентификатор проекта.
Доступ к данным режет **RLS на стороне сервера**: политики в `supabase.sql`
разрешают читать и писать строку только тому, у кого `auth.uid() = user_id`.
Без входа в аккаунт по этому ключу не получить ничего.

### Как пользоваться

Вкладка **Ещё → Синхронизация** → создать аккаунт (почта + пароль) →
войти той же почтой на втором устройстве. Дальше всё само:
отправка через 2 секунды после изменения, приём — при открытии.

**Слияние, а не затирание.** Отметки задач объединяются, галочки дня
складываются по блокам, статус «Закрыта» не откатывается назад,
отклики склеиваются по id. PIN никогда не уходит в облако.
